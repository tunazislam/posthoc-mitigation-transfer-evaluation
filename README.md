# posthoc-mitigation-transfer-evaluation
We show that post-hoc demographic mitigation should be evaluated across objectives, evaluators, and editing policies, introducing a frozen independent evaluation protocol and a pair-aware editing strategy that transfers more reliably than fixed-direction rewriting.

This repository contains code and data for the paper titled "When Objectives and Evaluators Disagree: Evaluating Transfer for Post-hoc Demographic Framing Mitigation".
